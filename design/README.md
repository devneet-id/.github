## Structure

Assets follow a consistent path convention:

```
<username>/<repo-or-topic>/<version-name>.<extension>
```

- **`<username>`** — your GitHub username.
- **`<repo-or-topic>`** — the project or theme the asset belongs to (e.g. `main`, `rune`, or anything relevant).
- **`<version-name>`** — a descriptive, versioned file name (e.g. `v2-logo-1`).
- **`<extension>`** — the file format (`svg` preferred).

**Example**

```
anwarachilles/main/v2-logo-1.svg
```
